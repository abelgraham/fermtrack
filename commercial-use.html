AGPL-3.0 Guide

Using FermTrack commercially is allowed.

You can sell hosting, setup, integration, customization, support, and training around FermTrack. The AGPL-3.0 license permits commercial use.

If users access a modified version of FermTrack over a network, AGPL requires you to offer those users the complete corresponding source code of the version they are using.
